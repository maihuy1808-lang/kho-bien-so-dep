Đăng nhập quản trị

Đăng nhập bằng mã truy cập GitHub của tài khoản maihuy1808-lang. Mã chỉ lưu trên máy anh, không gửi đi đâu ngoài GitHub.

Cách tạo mã truy cập (làm 1 lần)
  1. Mở GitHub → Tạo Fine-grained token (đăng nhập tài khoản maihuy1808-lang).
  2. Token name: Admin web bien so. Expiration: chọn 90 ngày hoặc 1 năm.
  3. Repository access: chọn Only select repositories → kho-bien-so-dep.
  4. Permissions → Repository permissions → Contents: chọn Read and write.
  5. Bấm Generate token, sao chép mã (bắt đầu bằng github_pat_) và dán vào ô trên.

Mã này chỉ sửa được kho website, không đụng tới gì khác trong tài khoản. Lộ mã thì vào GitHub xóa token là xong.
